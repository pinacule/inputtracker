# Thinker fonts

Downloaded 2026-10-26 as upstream Google Fonts Latin and Latin-ext WOFF2
subsets; no local glyph, outline or font name-table modifications. Upright
faces only, `font-display: swap`; no runtime Google/CDN requests.
The Cormorant and Source files are variable Roman fonts, so each subset is
stored once and shared by its requested weights. CSS alias “Thinker Plex Mono”
only avoids collisions with the app's existing Plex faces; binary names remain
unchanged. Reserved Font Names are retained in the original upstream files.

  `cormorant-garamond-500-600-latin-ext.woff2`: **Cormorant Garamond**, Christian
  Thalmann / Cormorant Project Authors, 500/600, **SIL OFL 1.1**.
  Source: https://github.com/google/fonts/tree/main/ofl/cormorantgaramond ;
  acquisition: https://fonts.googleapis.com/css2?family=Cormorant+Garamond:wght@500;600&display=swap ;
  full upstream notice/licence: [OFL.cormorant-garamond.txt](OFL.cormorant-garamond.txt).
