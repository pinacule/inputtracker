# Bundled fonts

All files are WOFF2 subsets (latin, latin-ext) taken from the Fontsource npm packages and are
licensed under the SIL Open Font License 1.1 (https://openfontlicense.org), which allows
bundling them with this app.

| Family | Designer | Used by |
|---|---|---|
| Instrument Serif | Instrument | default (Editorial) headings and numbers |
| Inter | Rasmus Andersson | default body text |
| Oswald | Vernon Adams et al. | hermes headings |
| Roboto Condensed | Christian Robertson | hermes body |
| IBM Plex Mono | IBM | signal, workbench and cwm text |
| Courier Prime | Alan Dague-Greene | signal headings |
| Pixelify Sans | Stefie Justprince | workbench headings and numbers |
